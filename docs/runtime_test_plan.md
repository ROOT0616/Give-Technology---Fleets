# 実機テスト手順（未実施）

対象：Stellaris 4.5.2 / 3.0.0-beta.1。まず本MODだけを有効にした新規ゲームで確認し、エラーログは最初のparser/script errorから調べる。

| ケース | 確認事項 |
|---|---|
| Launcher・起動 | ローカルMODが認識される。版番号・画像が表示され、布告2件を開ける。起動後の`error.log`に本MOD由来のunknown trigger/effect、invalid scope、重複ID、欠落locがない |
| 技術受諾・拒否 | 送付側保有・受領側未保有の通常技術を送る。受諾で表示した技術だけを取得。拒否で変化なし。消費資源と信頼度が勝手に変化しない |
| 前提・OR・国特性・DLC | 通常前提不足、ORの片側だけ保有、両側未保有、ゲシュタルト/機械/生体艦/遊牧国家、必要DLC有無で条件が妥当。tier・抽選重みと贈与条件の違いを確認 |
| 技術一覧 | 全分野・全ティアを前後移動。空ページから復帰できる。特殊・反復・削除済み技術が出ない。選択名と取得技術が一致 |
| 艦隊受諾・拒否 | 通常軍事艦隊を贈与。受諾で艦船数・装備を保持し所有権と制御権が相手国へ移る。司令官は元の帝国に残る。拒否では変化なし |
| 貸与・共有艦隊 | 貸与中/傭兵・戦闘中の艦隊が出ない。連邦議長・守護者・皇帝からは通常艦隊も出ない。議長交代後や保留中の役職変更にも制限が働く。GDF/連邦/帝国軍が移転しないことを確認 |
| 候補境界 | 通信先0・1・13・14か国以上、対象艦隊0・1・10・11個以上で候補の実在・重複非表示・再抽選を確認。対象消滅後も閉じられる |
| 保留中の変更 | 受諾前に技術取得、国家滅亡、通信喪失、開戦、艦隊売却/合流/分割/壊滅/戦闘入り/貸与開始。成立しない条件では移転・付与が起きない |
| 同時取引・マルチ | 2人の送付国から同じ受領国へ、同じ送付国から複数国へ、技術と艦隊を同時に申し込む。古い申し出が新しい対象を使わない。同艦隊の複数申し出で二重移転しない。OOSなし |
| AI | AIの受諾・拒否が進む。AIが布告から自発的に贈与しない。無効な申し出でも閉じられる |
| 保存・復帰・削除 | 新規4.5.2、既存4.5.2への追加、選択中・申し出保留中・受諾後のセーブ/ロードを確認。旧2.0.1の保留中セーブは対応対象外。贈与完了後のMOD削除で既取得技術と所有権が残ることを確認 |
| 3言語 | 日本語・英語・簡体字中国語で文字化け、未翻訳キー、名前表示、ページ送り、画面外へのはみ出しを確認 |

実施時にはゲーム版・checksum、DLC、併用MOD、手順、期待結果、実測結果、最初の関連ログを記録する。通過後に安定版化と、共有艦隊を個別判定できる公式script hookの追加調査を行う。
