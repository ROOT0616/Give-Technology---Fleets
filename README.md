# Give Technology & Fleets

Stellaris **4.5.2「Cygnus」向け更新候補 / 3.0.0-beta.1**。2026-10-23時点の調査に基づきます。**ゲーム内動作は未検証**です。

布告から、技術の即時贈与と軍事艦隊の恒久贈与を申し込むMODです。相手国には受諾・拒否の選択肢が表示されます。金銭・資源による対価は徴収しません。

## バニラとの重複

| 機能 | 提供Vanillaでの確認 | このMODとの差 |
|---|---|---|
| 研究協定 | 外交アクションと取引項目。相手国の既知技術への研究速度補正 | このMODは選んだ技術を即時取得させる |
| 艦隊貸与 | 「Borrow Fleet」、一定年数の借用と返却表示 | このMODは所有権と制御権を恒久移転する |
| 傭兵艦隊の雇用 | enclaveイベントの貸与処理 | 自国艦隊を任意の相手国へ無償譲渡する処理とは異なる |

研究協定や期限付き貸与が目的ならバニラの機能で対応できます。即時技術贈与と恒久所有権移転について、今回確認した外交・取引GUI・localizationには同等の通常取引項目を確認できませんでした。取引の一部はengine側にあり、スクリプト検索だけで全DLC・全状況の不在を証明したものではありません。詳細は[調査記録](docs/compatibility_audit.md)を参照してください。

## 使い方

1. 布告「技術の贈与」または「艦隊の贈与」を選択します。
2. 通信確立済みで交戦していない通常帝国から相手国を選びます。ランダムに最大13か国を表示し、再抽選できます。
3. 技術は分野・ティアを選び、12件ずつのページから選択します。艦隊は最大10艦隊の候補から選択し、再抽選できます。
4. 相手国が受諾すると贈与が成立します。相手国は拒否できます。

空の技術ページは「次のページ」で進めます。候補を状況に応じて並べ替える機能はありません。

## 3.0.0-beta.1の仕様と制限

- 提供Vanillaの678技術定義を調査し、**467技術**を贈与対象として生成しています。分野・tier 1–5が対象です。
- 自国の保有、相手国の未保有、相手国側の前提技術（OR条件を含む）とVanilla `potential`を確認します。受諾時にも再確認します。
- 反復技術、開始時技術、対象ティア外、基礎抽選重み`weight = 0`のイベント用・特殊技術は対象外です。除外理由は[技術一覧](docs/technology_catalog.json)に記録しています。旧版で渡せた一部の特殊技術も対象外になっています。
- 研究候補の抽選・AI研究選択を再現する機能ではありません。`weight_modifier`、抽選用のティア解放条件、研究コストは贈与の条件にしません。受領後の研究・解放効果は実機確認が必要です。
- 艦隊は移動可能・軍事クラス・非貸与・非戦闘中で、贈与元が所有していることを確認します。受諾時にも確認します。司令官は移転前に解除され、贈与元に残ります。
- **連邦議長・銀河守護者・銀河皇帝は、このベータでは通常艦隊も送付できません。** 提供Vanillaで共有艦隊を確実に区別できる専用triggerを確認できなかったため、所有者の役職で保守的に制限します。通常の連邦加盟国は対象です。これで全特殊艦隊・他MOD艦隊の安全性を保証するものではありません。
- 同じ艦隊への複数の申し出は、先に成立したものだけが移転でき、所有者が変わった後の受諾は不可になります。申し出後の艦隊分割・合流・消滅・指導者交代は実機未検証です。
- AIは自発的に贈与しません。受領側AIの選択重みは有効な申し出で受諾10、拒否1です。実際の選択はゲーム内未検証です。旧版の信頼度加算は撤去しました。
- 日本語・英語・簡体字中国語を同一キー構成、UTF-8 BOMで用意しています。訳文とGUI上の収まりは実機未検証です。
- 他MODで追加された技術は自動では一覧に追加されません。既存Vanilla技術の`potential`や前提条件を他MODが変更した場合、このMODの生成済み条件とは一致しなくなる可能性があります。

## インストール

配布ZIPをStellarisのユーザーデータ内の`mod`ディレクトリへ展開します。標準的なWindows環境では`Documents/Paradox Interactive/Stellaris/mod`です。OneDrive等でDocumentsが移動されている場合は実際の保存先を使用してください。

```text
mod/
  GiveTechnologyFleets.mod
  GiveTechnologyFleets/
    descriptor.mod
    common/
    events/
    localisation/
    thumbnail.png
    README.md
```

GitHubの「Download ZIP」は開発用配置です。手動で使う場合はリポジトリの内容を`GiveTechnologyFleets`フォルダに置き、`GiveTechnologyFleets.mod`をその一つ上の`mod`ディレクトリへコピーします。旧Workshop版とローカル版を同時に有効にしないでください。

## 互換性・セーブ

- 対象は**4.5.2のみ**。`supported_version`も4.5.2です。4.6への対応は宣言していません。
- Vanilla定義のoverride、`replace_path`、GUI上書き、Vanilla localization上書きはありません。名前空間は既存の`gft_tech_trade` / `gft_fleet_trade`、独自定義は`gft_`です。
- 同じnamespace・定義名を持つ旧版や派生MODとは競合します。技術・艦隊・国タイプを変更するMODとの併用は未検証です。
- 既存の**4.5.2セーブへ追加可能と見込まれますが、安全性は未確認**です。バックアップしたコピーで試してください。開始時イベントや移行イベントは追加していません。
- **2.0.1からの更新は新規ゲーム推奨**。旧版のイベントID・グローバル対象・取引フラグを再利用しないため、申し出やメニューを残したセーブへの上書き更新は非対応です。旧取引をすべて終えて保存するか、新規ゲームを使用してください。旧フラグ等の削除migrationは実装していません。
- 旧Stellaris版から4.5へのセーブ移行の安全性は本MODでは保証できません。提供Vanillaの開始案内にも4.5でセーブ・MOD互換性がリセットされる旨が記載されています。
- MODを無効化しても贈与済み技術・艦隊所有権は巻き戻りません。開いたイベントを残した状態での削除は避けてください。

## 検証

[静的検証結果](docs/static_validation.json)では、522イベントのID重複・参照切れ・到達不能、467技術の実在と付与対応、前提条件とOR構造、受領国potential、3言語のキー・BOM、メタデータ、Vanilla定義との名前衝突を検査しています。

**Stellaris本体は起動していません。** Launcher認識、ゲームのparser/scope判定、`error.log`、UI、AI応答、ネットワーク同期、セーブ/ロードは未検証です。Python検査でPASSでもengineの動作保証にはなりません。次の作業は[実機テスト手順](docs/runtime_test_plan.md)の実施です。

## 開発・再生成

Python 3.12標準ライブラリで実行できます。Vanillaの展開先には`common`、`events`、`interface`、`localisation`を配置してください。Vanilla実ファイルをリポジトリへ追加しないでください。

```text
python tools/generate.py <Vanilla展開先>
python tools/localize.py
python tools/validate.py <Vanilla展開先>
python tools/package.py
```

生成元の技術仕様が変わった場合は、出力差分と受領条件をレビューしてください。未確認の構文は生成時に停止します。`tools/clausewitz.py`は静的調査用の簡易readerで、ゲームのparserの代替ではありません。
